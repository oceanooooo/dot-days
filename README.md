# 도트 데이즈 (Dot Days) — 여름날의 루틴 RPG

할 일과 루틴을 **퀘스트**로 완료하면 경험치·조개·도트 아이템을 얻고, 모은 조개로 내가 정한 현실 보상을 사는 게이미피케이션 루틴 앱입니다.

- **바로 쓰기**: https://oceanooooo.github.io/dot-days/
- **체험 모드**(예시 데이터, 저장 안 됨): https://oceanooooo.github.io/dot-days/?demo

## 설치 (홈 화면에 추가하면 앱처럼 실행되고 오프라인에서도 동작)

| 기기 | 방법 |
|---|---|
| iPhone · iPad | Safari로 열기 → 공유 버튼 → 홈 화면에 추가 |
| Android | Chrome으로 열기 → ⋮ → 앱 설치 |
| Mac | Safari: 파일 → Dock에 추가 / Chrome: 주소창 오른쪽 설치 아이콘 |

## 주요 기능

퀘스트(반복·횟수·연속 기록) · 경험치·레벨·능력치 6종 · 조개 상점(내가 정한 보상) · 가방·보물상자 · 업적 28종 · 도감 · 집중 다이빙(뽀모도로) · 디데이 계산기·관리 · 기록 잔디 · 백업 파일 · GitHub Gist 기기 간 동기화

## 데이터와 개인정보

- 기록은 이 기기 브라우저에만 저장됩니다. 서버·광고·분석 도구가 없습니다.
- 동기화를 켜면 내 GitHub 계정의 **비공개 Gist**에만 저장됩니다. 토큰은 기기에만 보관됩니다.
